## Objetivo do software
O Cenaflix tem como objetivo facilitar o gerenciamento de filmes, permitindo cadastrar, consultar, pesquisar, atualizar e excluir informações por meio de uma aplicação desktop conectada a um banco de dados MySQL.

## Funcionalidades do sistema
- Cadastro de filmes.
- Consulta dos filmes cadastrados.
- Pesquisa de filmes por categoria.
- Atualização dos dados dos filmes.
- Exclusão de filmes.
- Conexão com banco de dados MySQL.
- Armazenamento e gerenciamento das informações dos filmes.
